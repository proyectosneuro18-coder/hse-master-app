[Identidad visual global, toda la pantalla ~8707px] Las 2 franjas de cinta de peligro (header y pre-footer, 6px cada una) y el ícono de casco (2 apariciones, ~13px) son las únicas señas industriales sostenidas; en los ~8700px de scroll entre ellas, el lenguaje dominante (tarjetas redondeadas con borde grueso, botones con borde-inferior 3D, paleta multicolor saturada) sigue leyéndose como el mecanismo de Duolingo re-coloreado — las franjas son demasiado delgadas y escasas para registrarse sin buscarlas → subir el grosor de las 2 franjas existentes a 8-10px y añadir una tercera entre "Agitación" (fin) y "Solución" (inicio), que es el quiebre narrativo problema→mecanismo.

[`.pregunta-card` y `.agita-card`, 8 tarjetas en total, landing.html ~L378-421] El ícono de fondo rojo (`var(--rojo)`) se usa en las 8 tarjetas de "¿Te suena familiar?" y "Agitación" para contenidos dispares (pregunta genérica, documento, lupa, foco/idea), no solo para alerta/urgencia real — esto contradice la propia regla de FICHA-ARTE.md ("Rojo: alerta/urgencia") y diluye el sistema cromático a "rojo = cualquier cosa negativa" → reservar el rojo a 1-2 tarjetas que agitan la urgencia real (responsabilidad legal/fatalidad) y usar un neutro oscuro para los íconos puramente informativos (documento, lupa).

[landing.html L20, `html { scroll-behavior: smooth; }`] A diferencia de cada otra animación del archivo (reveal, hero, barras, FAQ, sticky, subir-arriba), que sí están envueltas en `@media (prefers-reduced-motion: reduce)`, el scroll suave global no tiene ese gate — un usuario con movimiento reducido activado igual recibe scroll animado al tocar cualquier ancla (`#oferta`) → envolver la regla en `@media (prefers-reduced-motion: no-preference)` o quitar `scroll-behavior:smooth` del CSS global.
